# API для управления библиотекой (DF1)



## Описание проекта

Разработана REST API для управления библиотекой. 
API предоставляет возможности для управления книгами, 
авторами и пользователями, а также отслеживанием выдачи книг пользователям. 

## Стек технологий:
- Backend: Django и Django Rest Framework (DRF) для реализации проекта.
- База данных: PostgreSQL для хранения данных.
- Контейнеризация: Docker и Docker Compose для контейнеризации приложения.
- Документация API: Автогенерируемая документацию API по стандарту OpenAPI (Swagger / ReDoc).
- Аутентификация: JWT (используя djangorestframework-simplejwt)
- Качество кода: Весь код храниться в удаленном Git репозитории. Соблюден PEP8.

## Основной функционал:
**Управление книгами**:
- Создание, редактирование и удаление книг.
- Получение списка всех книг.
- Поиск книг по различным критериям (название, автор, жанр и т.д.).

**Управление авторами**:
- Создание, редактирование и удаление авторов.
- Получение списка всех авторов.
- 
**Управление пользователями**:
- Регистрация и авторизация пользователей.
- Получение информации о пользователях.

**Выдача книг**:
- Запись информации о выдаче книги пользователю.
- Отслеживание статуса возврата книги.

## Запуск Docker
1. Запустить Docker.

2. Выполните команду и дождитесь завершения:
```bash 
docker-compose up -d --build
```
3. Дождитесь завершения процесса сборки и запуска контейнеров

4. Создайте суперпользователя:
```bash
docker-compose exec app python manage.py csu
```

## Установка

1. Клонируйте репозиторий

```bash
git clone https://github.com/syoumanator/LibraryProject.git
```

2. Установите зависимости

```bash
pip install -r requirements.txt
```

3. Создайте файл .env и заполните по образцу .env_sample

4. Примените миграции

```bash
python manage.py migrate
```

5. Создайте суперпользователя

```bash
python manage.py csu
```

6. Заполните БД тестовыми данными
```bash
python manage.py loaddata author_fixture.json
python manage.py loaddata books_fixture.json
```
7. Запустите проект
```bash
python manage.py runserver
```
8. Для корректной работы необходим Reids 

8. Выполните команды:
```bash
celery -A config worker -l INFO -P eventlet
celery -A config beat -l INFO
```
